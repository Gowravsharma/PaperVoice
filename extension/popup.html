Let the extension start the reading engine

Once, in the project folder, run:

uv run papervoice-setup

Then click this icon again. From then on the engine starts by itself and stops after a while without use. (Or start it yourself: uv run papervoice-server.)

For a PDF opened from your disk, allow file access: Extensions → PaperVoice → Details → Allow access to file URLs.
